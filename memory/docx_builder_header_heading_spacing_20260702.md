For official DOCX generated by `skills/docx-builder`, wide-looking heading gaps
can come from renderer text, not Markdown. The stable heading format is one
space between section number and title, for example `1 Muc dich`, not two manual
spaces.

If the gap from header to body looks too large in Office PDF, check the generated
header XML first. A trailing empty paragraph or loose header paragraph spacing can
force Word to push body content down. The stable fix is to use compact header
paragraph line spacing and a body section top margin that still leaves room when
a page starts with a table.
